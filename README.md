## 📊 Featured Project

### Ethereum 30-Day Network Activity Analysis

An end-to-end blockchain analytics project investigating
Ethereum Mainnet activity over a 30-day observation window.

**Analysis Period:** August 24 – September 23, 2026

**Key Areas Investigated:**

- Ethereum transaction activity and network utilization
- Active address participation
- Gas usage and gas price behavior
- Transaction execution outcomes
- Network activity anomalies
- Relationships between key blockchain metrics

**Methodology:**

Extracted and aggregated Ethereum blockchain data using
Google BigQuery and SQL, followed by data validation,
exploratory analysis, statistical evaluation, and
visualization using Python.

**Tech Stack:** Python · SQL · Pandas  · BigQuery · MySQL ·
Matplotlib · Plotly
